# Pixel typography

Fusion Pixel 12px proportional, Simplified Chinese variant, release 2026.09.25. Source: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.25. The font and its included upstream components use the licenses provided beside the asset. The plugin changes font families only and preserves font sizes and colors. SVG artwork and mathematical typesetting retain their glyph systems. Disable this optional plugin to restore the previous font families.
